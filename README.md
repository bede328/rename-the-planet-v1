Entry for the [Rename the Planet](https://make.fun/c/u-motasimfuad-rename-the-planet-094b0369) competition on make.fun.

The program writes one line — a funny new name for a planet of our solar system, plus the why, in the same breath — to `/output/entry.txt` (UTF-8, one line, under 200 characters).

```sh
node main.ts
cat /output/entry.txt
```

The chosen line:

> Jupiter is now The Bouncer, because it eats every asteroid that tries to sneak past it to Earth.

Jupiter's gravity really does sweep up asteroids and comets that would otherwise reach Earth — the biggest planet in the solar system, working the door.
